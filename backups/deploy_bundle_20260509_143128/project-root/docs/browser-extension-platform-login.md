# 浏览器扩展平台登录

## 目标
- 保持现有“平台登录”页面 UI 不变
- 用户点击哪个平台，就打开哪个平台官方登录页
- 用户在自己浏览器完成登录
- 扩展自动读取登录 Cookie 并回传后端保存

## 扩展目录
- `scripts/browser-extension/platform-login-helper`

## 本地加载方式
1. 打开 Chrome 或 Edge 扩展管理页
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择目录 `scripts/browser-extension/platform-login-helper`

## 使用流程
1. 登录后台
2. 打开“平台登录”页面
3. 点击任一平台“发起登录”
4. 浏览器会打开对应平台官网登录页
5. 完成登录后，扩展会自动把 Cookie 回传到后端
6. 页面收到扩展消息后自动更新账号状态

## 当前边界
- 当前扩展第一版只做 Cookie 自动回传
- 当前账号名默认由后端兜底生成，后续可再补平台页面账号名自动识别
- 当前后端 `validate` 仍是轻量格式校验，不是平台在线验活
