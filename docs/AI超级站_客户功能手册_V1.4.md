## 1. 产品简介

AI 超级站是一套覆盖后台运营、商品管理、企业名片展示和前台触达的系统。  
本次手册重点补充：

- 企业名片能力
- 登录设备会话管理
- 商品英文名能力

---

## 2. 登录与会话

### 2.1 登录规则

- 使用后台账号密码登录
- 登录成功后系统自动创建一条会话记录
- 同一个账号最多允许 2 台设备同时在线
- 第 3 台设备登录时，系统会自动挤掉最早登录设备
- 登录不做固定时效主动过期

### 2.2 常用接口

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| POST | `/api/auth/logout` | 当前设备退出 |
| GET | `/api/auth/me` | 获取当前用户、角色、权限、数据范围 |
| GET | `/api/auth/sessions` | 查看当前账号在线设备 |
| DELETE | `/api/auth/sessions/:id` | 手动下线某个设备 |

### 2.3 使用说明

- 如果同事提示“账号被挤下线”，优先检查是否有第 3 台设备新登录
- 如果要主动清理旧设备，可在在线设备列表中手动下线

## 3. 企业名片

### 3.1 业务说明

- 每个后台账号一张企业名片
- 名片与后台账户强绑定
- 小程序 / H5 / 前台名片页复用后台账号与名片数据

### 3.2 可维护内容

- 企业名称
- 职位/岗位
- 手机号
- 邮箱
- 主营业务
- 封面图
- 名片模板

### 3.3 常用接口

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/business-cards/me` | 获取我自己的名片 |
| PUT | `/api/business-cards/me` | 更新我自己的名片 |
| GET | `/api/business-cards/:userId` | 获取某个用户的名片展示页信息 |
| POST | `/api/business-cards/me/cover` | 上传名片封面图 |

### 3.4 使用流程

1. 用户进入企业名片页
2. 系统读取当前账号名片
3. 用户修改名称、岗位、联系方式、主营业务
4. 如需更换视觉，上传封面图并切换模板
5. 保存后，小程序 / H5 / 前台名片页按同一账号数据展示

## 4. 商品英文名

### 4.1 业务说明

- 商品新增英文名字段
- 中文产品名录入后自动生成英文产品名
- 用户可手动调整英文名
- 列表、搜索、保存统一支持英文名

### 4.2 常用接口

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/products` | 查询商品列表，支持英文名 |
| POST | `/api/products` | 创建商品 |
| GET | `/api/products/:id` | 获取商品详情 |
| PUT | `/api/products/:id` | 更新商品 |
| DELETE | `/api/products/:id` | 删除商品 |
| POST | `/api/products/:id/submit` | 提交审核 |
| PUT | `/api/products/:id/special-offer` | 更新特价 |
| POST | `/api/products/infer-english-name` | 自动生成英文名 |

### 4.3 使用流程

1. 输入中文产品名
2. 系统自动生成英文名
3. 用户确认或手动调整英文名
4. 继续填写描述、价格、图片等商品信息
5. 保存或提交审核

## 5. 产品管理使用说明

### 5.1 主公司

- 可查看全部商品
- 可创建商品
- 可直接上架或审核代理商品
- 可查看中文名与英文名

### 5.2 1 级代理

- 只能管理自己的商品
- 可创建、编辑、删除自己的商品
- 可提交审核
- 不可直接上架

### 5.3 特价规则

- 未启用特价时，仅展示售价
- 启用特价后，展示原价、特惠价和特价标签

## 6. 前端 Demo 对齐说明

根据当前业务规划，前端 store 应承接以下方法：

| 领域 | 方法 | 说明 |
|------|------|------|
| 企业名片 | `ensureBusinessCard(userId)` | 初始化或确保名片存在 |
| 企业名片 | `updateBusinessCard(userId, payload)` | 更新名片 |
| 企业名片 | `getBusinessCardByUserId(userId)` | 获取公开名片 |
| 商品英文名 | `inferEnglishProductName(name)` | 推断英文名 |
| 商品创建 | `addProduct()` | 创建商品并自动带出英文名 |

## 7. 常见业务规则

### 7.1 企业名片

- 每个账号一张名片
- 名片不允许脱离后台账户独立维护
- 名片展示页按账号维度复用

### 7.2 登录设备限制

- 最多 2 台设备同时在线
- 第 3 台登录挤掉最早设备
- 当前设备登出不影响其他设备

### 7.3 商品英文名

- 自动生成不是强制最终值
- 用户拥有最终编辑权
- 检索时中英文应同时可命中
