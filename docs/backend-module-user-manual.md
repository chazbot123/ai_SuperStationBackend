# 后台模块用户操作手册

## 1. 适用范围
- 适用于 `AI 超级站后台`
- 适用于主公司账号与一级代理账号
- 以当前后台实际菜单与页面为准

## 2. 角色说明
- `主公司`：可查看全局数据，负责审核、上架、权限和全局配置
- `一级代理`：主要使用生成、商品、发布、超级站配置等业务模块

## 3. 登录后台
- 入口：后台登录页
- 输入账号和密码
- 勾选用户协议
- 点击“登录后台”

常见问题：
- 提示登录失效时，先确认账号密码是否正确
- 新环境若没有账号，先执行数据库种子初始化

## 4. 仪表盘
- 菜单名称：`仪表盘`
- 主要对象：主公司

可做什么：
- 查看内容池、发布任务、平台账号、客户线索、客服会话、知识库、商品的汇总数据
- 查看当天新增数据和成功/失败情况

建议操作：
1. 先看今日新增线索、内容、客服会话
2. 再看发布成功数、失败数
3. 如有异常，进入对应模块继续处理

## 5. 图片/文案生成

### 5.1 草稿箱
- 菜单路径：`图片/文案生成 -> 草稿箱`

可做什么：
- 查看图文草稿和商品图草稿
- 搜索标题或正文
- 编辑标题、正文、标签和图片
- 删除草稿
- 将图文草稿同步到产品管理
- 提交审核或撤销审核

标准操作：
1. 进入草稿箱
2. 用搜索框筛选目标草稿
3. 点击草稿进入“草稿编辑”
4. 修改标题、正文、标签、图片
5. 按需要执行“保存”“同步到产品管理”“提交审核”

### 5.2 社媒图文生成
- 菜单路径：`图片/文案生成 -> 社媒图文生成`

可做什么：
- 输入生成要求
- 选择比例等基础参数
- 生成标题、正文、标签和图片结果

标准操作：
1. 输入主题、卖点、场景、补充要求
2. 需要时点击“润色提示词”
3. 点击“开始生成”
4. 生成完成后检查结果
5. 需要继续编辑时，转到草稿箱处理

### 5.3 商品图与详情图生成
- 菜单路径：`图片/文案生成 -> 商品图与详情图生成`

可做什么：
- 生成商品标题、文案、标签和商品图
- 编辑结果区内容并保存到草稿

标准操作：
1. 填写商品名称、补充要求、提示词
2. 选择比例等参数
3. 点击“开始生成”
4. 在结果区检查标题、文案和图片
5. 需要进一步使用时，转到草稿箱或产品管理

## 6. AI获客

### 6.1 获客内容池
- 菜单路径：`AI获客`

可做什么：
- 查看已入池素材
- 对素材发起一键发布
- 查看发布记录
- 删除无效发布记录

标准操作：
1. 在内容池中找到目标素材
2. 点击“一键发布”
3. 选择目标平台
4. 选择或确认发布账号
5. 按平台补充标题、正文、标签等草稿内容
6. 点击“发布”
7. 到“发布记录”查看状态

### 6.2 门店搜索
- 菜单路径：`AI获客 -> 门店搜索`

可做什么：
- 配置搜索条件
- 查看地图预览
- 查看搜索结果
- 打开门店详情
- 将搜索结果导入后续业务链路

标准操作：
1. 填写地区、关键词等条件
2. 点击查询
3. 先看地图预览，再看结果表格
4. 打开“门店详情”确认信息
5. 按页面操作继续导入

### 6.3 平台登录
- 菜单路径：`AI获客 -> 平台登录`

可做什么：
- 连接本地客户端
- 发起抖音、小红书、视频号等平台登录
- 管理平台账号列表
- 校验、刷新、删除账号

标准操作：
1. 先确认“本地客户端状态”为已连接
2. 在“连接新频道”里选择平台
3. 按提示完成本地登录
4. 登录完成后到“平台账号列表”确认状态是否在线
5. 发布前先确认账号是有效状态

## 7. 产品管理
- 菜单名称：`产品管理`

角色差异：
- 主公司：可查看所有一级代理商品，可直接上架/下架
- 一级代理：可管理自己的商品，上架前需要提交审核

可做什么：
- 新增产品
- 编辑产品
- 删除产品
- 设置特价信息
- 提交审核
- 上架或下架

标准操作：
1. 点击“新增产品”
2. 填写产品名称、英文名、类别、摘要、详情、价格、图片
3. 保存产品
4. 一级代理继续点击“提交审核”
5. 主公司审核通过后执行“上架”
6. 前台只展示已上架商品

## 8. 知识库管理
- 菜单名称：`知识库管理`
- 主要对象：主公司

可做什么：
- 上传知识文件
- 选择知识库作用域
- 查看切片数、状态和任务
- 删除文件
- 做检索测试

支持文件：
- `pdf`
- `docx`
- `pptx`
- `txt`
- `md`
- `png`
- `jpg`
- `jpeg`
- `webp`

标准操作：
1. 选择并上传文件
2. 选择作用域，如公司知识库
3. 可选填写标题
4. 等待文件进入可用状态
5. 在列表中点“详情”查看切片数和任务记录
6. 在“检索测试台”输入问题测试召回结果

说明：
- 当前切片策略为“智能切片优先，固定切片回退”

## 9. 客户管理
- 菜单名称：`客户管理`
- 主要对象：主公司

可做什么：
- 查看客户线索
- 搜索客户
- 按平台来源筛选
- 新增客户
- 编辑客户
- 删除客户
- 导出 Excel

标准操作：
1. 先按姓名、电话、地址、备注或平台名搜索
2. 需要时按平台来源筛选
3. 点击“查询”
4. 点“编辑”修改客户详情
5. 需要汇总时点击“导出 Excel”

## 10. 视频生成

### 10.1 视频草稿箱
- 菜单路径：`视频生成 -> 草稿箱`

可做什么：
- 查看视频草稿
- 搜索标题或脚本
- 编辑标题、脚本和发布信息
- 提交审核或同步业务链路

### 10.2 产品视频生成
- 菜单路径：`视频生成 -> 产品视频生成`

可做什么：
- 上传首帧图片
- 输入产品视频脚本或提示词
- 生成短视频

标准操作：
1. 上传首帧图片
2. 输入产品信息和口播要求
3. 需要时润色文案
4. 发起生成
5. 生成完成后到草稿箱继续编辑和管理

### 10.3 真人口播视频生成
- 菜单路径：`视频生成 -> 真人口播视频生成`

可做什么：
- 上传人物肖像图
- 粘贴长文本脚本
- 自动拆段生成多个视频片段
- 合成完整口播视频

标准操作：
1. 上传正面肖像图
2. 粘贴完整口播脚本
3. 选择场景和语音
4. 发起生成
5. 结果生成后进入草稿箱检查和编辑

## 11. AI客服
- 菜单名称：`AI客服`

子模块：
- `客服后台`
- `开发测试台`

### 11.1 客服后台
可做什么：
- 查看会话列表
- 搜索访客、联系方式或消息内容
- 按状态筛选
- 人工接线
- 人工回复
- 结束会话

标准操作：
1. 在左侧筛选会话
2. 点开目标会话
3. 如需人工接管，点击“接线”
4. 输入回复内容并发送
5. 完成后结束会话

说明：
- 系统会自动轮询刷新会话
- 新的待人工会话会有提醒

## 12. 超级站配置中心
- 菜单名称：`超级站配置中心`
- 可用角色：主公司、一级代理

子模块：
- `图片视频设置`
- `运营指标`
- `行业与招商`

### 12.1 图片视频设置
可做什么：
- 维护超级站图片槽位
- 上传图片或从图文草稿箱选图
- 上传视频或从视频草稿箱选视频

标准操作：
1. 进入图片视频设置
2. 找到对应图片位或视频位
3. 选择本地上传或从草稿箱选择
4. 保存设置
5. 到前台页面核对展示效果

### 12.2 运营指标
可做什么：
- 控制指标是否显示
- 设置固定值或动态值
- 预览前台指标效果

标准操作：
1. 选择一个指标
2. 设置显示/隐藏
3. 选择固定值或动态值
4. 若是动态值，填写起始值、间隔和增量区间
5. 点击“保存”
6. 在右侧预览效果

### 12.3 行业与招商
可做什么：
- 维护抓取来源
- 配置关键词和每日抓取时间
- 立即同步行业信息
- 新增手工行业信息
- 编辑、置顶、删除行业信息

标准操作：
1. 先勾选启用的抓取来源
2. 填关键词和抓取时间
3. 点击“保存配置”
4. 需要即时更新时点“立即抓取”
5. 在列表里编辑、置顶或删除内容

## 13. 模型配置
- 菜单名称：`模型配置`

可做什么：
- 分别维护文字、图片、视频模型
- 配置服务商、Base URL、API Key、模型名称
- 测试连接
- 保存并启用

标准操作：
1. 先选择模型类型：文字、图片或视频
2. 选择服务商
3. 填写 Base URL、API Key、模型名称
4. 图片/视频模型按需填写任务查询地址模板
5. 点击“测试连接”
6. 测试成功后点击“保存并使用”

说明：
- 当前模型配置按登录账号隔离，不同账号互不共用

## 14. 审核中心
- 菜单名称：`审核中心`

子模块：
- `素材审核`
- `商品审核`

### 14.1 素材审核
可做什么：
- 审核图文草稿、商品图草稿、视频草稿
- 查看提交内容
- 通过或驳回

### 14.2 商品审核
可做什么：
- 审核一级代理提交的商品
- 查看商品详情、价格和图片
- 通过后进入上架流程

建议流程：
1. 先处理待审核内容
2. 驳回时填写清楚原因
3. 商品通过后再到产品管理执行上架

## 15. 用户/角色/权限
- 菜单名称：`用户/角色/权限`
- 主要对象：主公司

子模块：
- `用户管理`
- `角色管理`
- `权限矩阵`

### 15.1 用户管理
可做什么：
- 新增用户
- 编辑用户
- 重置密码
- 调整所属角色

标准操作：
1. 进入用户管理
2. 点击“新增用户”
3. 填写用户名、密码、显示名、公司名、角色
4. 保存后通知对应人员登录

### 15.2 角色管理
可做什么：
- 新增角色
- 编辑角色名称和说明
- 删除自定义角色

### 15.3 权限矩阵
可做什么：
- 控制每个角色是否可访问某个页面模块
- 调整页面级访问权限

建议操作：
1. 先确认角色
2. 再改页面权限
3. 修改后重新核对账号实际菜单是否符合预期

## 16. 常见使用顺序

### 16.1 内容发布链路
1. 在图片/文案生成或视频生成里产出内容
2. 到草稿箱编辑内容
3. 同步到内容池或产品管理
4. 在平台登录中准备好账号
5. 在 AI获客 中发起一键发布
6. 在发布记录里看结果

### 16.2 商品运营链路
1. 新增或编辑商品
2. 一级代理提交审核
3. 主公司到审核中心审核
4. 回到产品管理上架
5. 前台展示已上架商品

### 16.3 超级站配置链路
1. 配图片视频
2. 配运营指标
3. 配行业与招商
4. 到前台核对实际展示

## 17. 常见问题
- 登录提示失效：先确认账号、密码、登录状态
- 发布失败：先看平台账号是否在线，再看发布记录错误信息
- 商品前台不显示：确认商品状态是否为“已上架”
- 知识库不可用：确认文件状态是否为“可用”
- 客服无法人工处理：先确认会话状态是否待接线
- 超级站前台未更新：确认配置已保存，并检查前台访问的是正确站点
