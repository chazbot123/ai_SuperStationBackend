## 1. 项目背景

AI 超级站是一套面向企业客户交付的站点系统，包含前台官网、商品展示、内容生成、审核、获客、发布、AI 客服、知识库、模型配置、前台配置和用户权限管理。

系统采用模板化交付方式：

- 后台与后端尽量复用
- 客户之间主要差异通过前台项目层、配置和数据体现
- 不建议复制分叉后台和后端代码
- 当前部署边界已确认：独立服务器本地部署、单机部署、完整后台、单企业多部门、允许依赖外部 AI / API

当前推荐正式部署形态：

- 模块化单体 + Worker + Docker Compose 单机部署

推荐正式技术栈：

- 前端：React + TypeScript + Vite
- 后端：NestJS + TypeScript
- 数据库：PostgreSQL
- 缓存 / 队列：Redis + BullMQ
- 文件存储：MinIO
- 反向代理：Nginx

---

## 2. 产品目标

- 提供一套可复用的后台与后端模板，支持多客户快速交付
- 客户前台可独立呈现不同风格、不同模块内容、不同商品和知识库
- 主公司可统一控制代理生产内容与商品上架审核权限
- 降低单客户定制成本，提升交付和维护效率
- 在保持合规和真实性前提下，提高内容生产、商品运营和获客效率
- 支持企业名片、小程序 / H5 名片展示与后台账号体系打通
- 支持商品中英文名统一维护与展示
- 支持后台账号设备会话并发控制

---

## 3. 核心原则

- 优先级：真实性 > 合规性 > 可执行性 > 吸引力
- 后台和后端是模板层，客户差异通过前台项目层、配置层和数据层实现
- 前台允许按客户单独开发或基于旧前台小修小改
- 每个客户独立部署到自己的服务器、数据库、知识库目录和模型配置环境
- 所有生成模块优先输出结构化 JSON
- 主公司生成内容无需提交审核
- 1级代理生成内容必须手动提交审核
- 1级代理未提交审核前，不能同步任何下游模块
- 1级代理未审核通过前，预览素材默认带水印
- 获客内容池仅展示审核通过素材
- 前台只展示已上架商品
- 前台配置仅主公司可见可改
- V1 默认启用两个角色：主公司、1级代理
- 系统保留账号、角色、权限矩阵扩展能力
- 后台账号最多同时登录 2 台设备，第 3 台登录自动挤掉最早设备

## 4. 模板化交付架构

### 4.1 架构目标

系统采用“产品模板层 + 客户项目层 + 客户独立部署实例”的交付架构。

- 产品模板层负责统一的后台和后端模板能力
- 客户项目层负责客户前台代码、前台样式、站点内容和局部页面定制
- 最终每个客户都部署到自己的服务器和数据库中，形成独立运行实例

### 4.2 架构分层

#### 4.2.1 产品模板层

- 后台模板代码
- 后端模板代码
- 标准数据库模型
- 标准接口契约
- 标准商品流转
- 标准素材审核流
- 标准商品审核流
- 标准获客与草稿箱发布流
- 标准超级站上传入口契约
- 标准客服与知识库流程
- 标准企业名片管理流程
- 标准登录会话并发控制流程

#### 4.2.2 客户项目层

- 客户前台代码，可单独开发或基于旧前台小修小改
- 客户前台样式与页面结构
- 客户站点内容配置
- 客户知识库目录
- 客户模型配置
- 客户部署环境配置
- 客户名片页 / 小程序展示层

#### 4.2.3 客户部署实例

每个客户独立部署：

- 前台服务
- 后台服务
- 后端服务
- 数据库
- 知识库目录
- 模型配置
- 文件存储
- Redis / 队列

### 4.3 架构约束

- 不允许把客户特有业务逻辑写死到后台与后端模板主流程
- 前台允许客户级独立开发或小改，但前后端接口契约尽量标准化
- 后台和后端按模板复用，不建议为单客户分叉主干代码
- 客户差异优先通过前台项目层、配置层和内容层实现
- 审核流、发布流、生成流、客服流保持统一，不因客户而分叉代码
- 即使当前采用客户独立数据库部署，核心表仍建议预留 `siteId` 或 `siteCode` 字段，便于后续演进
- 知识库路径、模型配置、前台模板和站点模块配置按客户实例独立管理
- 上传超级站能力必须通过标准前台编辑入口契约实现，不允许为单客户写死跳转逻辑

## 5. 角色与权限

### 5.1 V1 预设角色

- `main_company`：主公司
- `level1_agent`：1级代理

### 5.2 角色定义

#### 5.2.1 主公司

主公司权限类似超管，可访问全部后台模块，可管理全部 1级代理的内容和商品，可自己上传商品、直接上架商品、审核 1级代理提交的素材和商品。

#### 5.2.2 1级代理

1级代理是权限受限角色，可访问：

- 图片 / 文案生成
- 视频生成
- 获客内容池
- 产品管理
- 企业名片

限制：

- 只能管理自己的商品
- 不能直接上架商品
- 不能审核素材
- 不能审核商品
- 不能管理前台配置
- 不能管理模型配置
- 不能管理知识库
- 不能管理用户、角色与权限

### 5.3 权限控制层次

- 登录鉴权
- 页面级权限
- 操作级权限
- 审核状态前置校验
- 发布资格前置校验
- 登录会话并发控制

## 7. 前台功能

### 7.1 全站公共能力

#### 7.1.1 语言切换

支持中英文切换，切换后刷新商品字段、配置字段和客服语言。

#### 7.1.2 公共运营指标组

包含：

- 访问量
- 咨询量
- 招商签约率
- 购买量

规则：

- 访问量：按天重置，动态跳动
- 咨询量：按天重置，动态跳动
- 购买量：累计动态跳动，不按天重置
- 招商签约率：固定配置值

位置：前台可配置，不强制右上角。

### 7.2 首页

- 产品展示区：展示所有已上架商品卡片，点击进入详情页
- 特价展示区：展示后台启用特价的商品，前台展示特惠价、原价划线和特价标签
- 结构化滚动条：每条数据包含字段名、字段值、描述，支持后台排序、启停
- 行业信息列表：统一展示自动抓取行业动态和后台手工行业信息，支持后台统一排序、置顶、启停
- 招商模块：支持直播链接或招商视频展示，仅主公司配置
- AI 客服入口：仅支持文字交流，支持转人工

### 7.3 产品列表

前台只展示状态为“已上架”的商品，不区分商品由主公司还是 1级代理创建。

### 7.4 产品详情

展示商品基础信息与图片素材，数量默认固定为 1。SKU 结构保留，但 V1 不启用复杂交互。

价格展示规则：

- 未启用特价时，仅展示售价
- 启用特价后，不再单独展示售价，改为展示特惠价、原价划线和特价标签

### 7.5 企业名片页

企业名片页展示某个后台账号对应的名片信息，可用于：

- H5 名片页
- 小程序名片页
- 对外分享页

展示内容包含：

- 公司名字
- 运营岗位
- 手机号
- 邮箱
- 主营业务
- 封面图背景
- 模板风格

### 7.6 AI 客服

V1 仅支持文本输入和文本回复。

对话状态：

- `AI_CHAT`
- `HANDOFF_OFFERED`
- `QUEUEING`
- `HUMAN_CHAT`
- `ENDED`

转人工采用 FIFO 排队，前台显示前方人数和排队提示。

## 8. 后台功能

### 8.1 登录

账号密码登录；未登录访问后台任意页时跳转登录页。主公司默认进入仪表盘，1级代理默认进入图片 / 文案生成页。

当前补充：

- 当前前端已支持 `main_company / level1_agent / department_admin / employee`
- 顶部已提供“修改密码”入口，所有登录账号都可修改自己的密码
- 主公司可在“用户管理”中直接修改任意账号密码

### 8.2 仪表盘

主公司展示完整仪表盘；1级代理默认不强调仪表盘。

主公司仪表盘展示：

- 待审核素材数
- 待审核商品数
- 今日生成数
- 今日同步获客数
- 今日发布成功数
- 图文已生成未预览数
- 视频已生成未预览数

区块包括：

- 生成概览
- 审核概览
- 发布概览
- 商品概览
- 前台运营概览

已生成未预览定义：生成任务已产出结果，但用户尚未首次打开预览详情。

### 8.3 产品管理

产品前后台关系类似“淘宝 / 千牛”模型：

- 前台负责展示已上架商品
- 后台负责商品运营、商品编辑、商品审核和商品上架

#### 8.3.1 商品列表

字段：

- 商品名称
- 英文产品名
- 所属创建人
- 状态
- 价格
- 特价状态
- 素材数量
- 更新时间

操作：

- 新增
- 编辑
- 上架 / 下架
- 提交审核
- 删除
- 排序

#### 8.3.2 商品编辑页

基础信息：

- 中文商品名
- 英文产品名
- 描述
- 状态
- 排序

价格规则：

- 未启用特价时，仅保留“售价”作为商品价格
- 启用特价后，不再单独填写“售价”
- 启用特价后改为填写“原价”、“特惠价”和“特价标签”

素材管理区：

- 统一图片素材列表
- 第一张自动作为主图
- 支持上传、删除、排序、预览

说明：

- 商品视频 V1 不启用
- SKU 保留结构但 V1 不启用
- 前台数量默认固定为 1

#### 8.3.3 商品权限与上架规则

主公司：

- 可查看所有 1级代理商品信息
- 可查看所有已上架商品
- 可自己创建商品、编辑商品、直接上架商品
- 可审核 1级代理提交的商品

1级代理：

- 可创建自己的商品
- 可编辑自己的商品
- 可上传商品图片素材
- 可提交商品审核
- 不能直接上架商品
- 只能管理自己的商品

#### 8.3.4 商品状态流转

- 草稿
- 待审核
- 已上架
- 审核驳回
- 已下架

流转规则：

- 主公司商品：草稿 -> 已上架，或 草稿 -> 已下架
- 1级代理商品：草稿 -> 待审核 -> 已上架 / 审核驳回
- 已上架商品可进入已下架

### 8.4 企业名片

企业名片作为独立模块，位于 `产品管理` 附近。

#### 8.4.1 业务模型

- 每个账号一张名片
- 名片与后台账户强绑定
- 名片表与后台账户表强关联
- 小程序名片系统复用后台账号密码登录

#### 8.4.2 企业名片字段

- 公司名字
- 运营岗位
- 手机号
- 邮箱
- 主营业务
- 封面图上传
- 预设模板选择
- 预览
- 保存

#### 8.4.3 页面能力

- 表单编辑
- 模板选择
- 封面图上传
- 实时预览
- 保存更新

#### 8.4.4 预览样式规则

当前预览样式为：

- 封面图作为整张文字信息区背景
- 叠加暗色遮罩与渐变
- 文字直接覆盖在背景图上
- 不是上图下文结构

### 8.5 商品英文名

商品管理新增英文产品名能力：

- 新增字段：`englishName`
- 填写中文产品名时自动生成 / 自动回填英文名
- 用户可以手动修改英文名
- 商品列表展示英文名
- 商品搜索纳入英文名

当前内置示例翻译映射包括：

- 智能名片系统 → Smart Business Card System
- AI电热采暖系统 → AI Electric Heating System
- 石墨烯节能墙暖 → Graphene Energy-saving Wall Heater
- 模块化地暖控制器 → Modular Floor Heating Controller

### 8.6 登录设备限制

后台账号登录会话规则：

- 每个账号最多同时登录 2 台设备
- 第 3 台设备登录时，自动挤掉最早登录设备
- 被挤掉设备的会话状态标记为 `squeezed`
- 登录时间不主动过期

当前补充：

- `GET /api/auth/sessions` 后端接口已实现
- 当前 demo 页面尚未提供设备会话列表入口

#### 8.8.2 商品图与详情图生成

用途：

页面能力：

- 审核通过后显示同步获客按钮
- 审核通过后显示同步产品管理按钮
- 不提供勾选、全选或批量提交审核

规则：

- 主公司可直接同步获客和产品管理
- 1级代理提交审核前不可同步获客，不可同步产品管理
