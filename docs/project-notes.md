# 项目注意事项

## 导航交互
- 侧边栏父导航如果包含子导航，必须提供明确的展开/收起交互
- 父导航右侧必须有箭头图标，箭头方向要随展开状态切换
- 子导航容器展开和收起时必须带过渡动画，避免内容突然出现或消失
- 当前 `图片/文案生成` 使用向下箭头展开子菜单，适用于后续同类父导航
- 当前 `视频生成` 也按同样模式处理为父导航下拉，包含 `产品视频生成 / 真人口播视频生成`

## Studio 模块
- `社媒图文生成` 使用后端 `SocialGeneratedPost` 作为正式结果来源
- `商品图与详情图生成` 当前先持久化到前端草稿 store，供草稿箱聚合展示
- 草稿箱用于聚合 `社媒图文生成` 和 `商品图与详情图生成` 两个子模块的结果
- `社媒图文生成` 和 `商品图与详情图生成` 页面本身不再展示结果模块，结果统一进入 `草稿箱`
- 草稿箱必须支持按 `全部草稿 / 社媒图文生成 / 商品图与详情图生成` 筛选
- 两个生成模块成功后，需要给 `草稿箱` 导航增加未预览红点计数，并展示素材飞入草稿箱的动效
- 草稿箱需要单独展示“正在执行的任务”，任务开始后立即可见，不等最终结果生成完成
- 当前任务进度为前端阶段进度：`queued / copy / images / saving / failed`

## 视频生成模块
- `产品视频生成` 和 `真人口播视频生成` 页面本身不再展示结果模块
- 两个视频子模块生成结果统一进入 `视频生成 -> 草稿箱`
- 视频草稿箱用于聚合两个视频子模块结果，并处理预览、提交审核、同步到获客
- `产品视频生成` 已接通后端真实任务，支持任务轮询、音频/BGM 后处理，并在最终成片默认烧录中文字幕
- `产品视频生成` 当前已拆分 `用户提示词 / 文案提示词 / 文案生成结果` 三条独立链路：提示词用于视频生成，文案提示词用于单独生成平台文案，结果区支持字数统计、5 行滚动与全屏编辑
- `真人口播视频生成` 已接通后端真实任务，支持脚本分片、BullMQ 队列推进、分片拼接，并在最终成片默认烧录中文字幕
- `真人口播视频生成` 当前定义为：`用户提示词` 用于视频生成，`文案内容` 根据用户提示词生成；若未明确指定字数，则默认生成符合提示词内容的完整成稿
- `真人口播视频生成` 的 `用户提示词` 点击 `润色` 时会自动补全视频生成缺失信息；如需语音，需在提示词中显式填写 `语音内容 / 旁白 / 口播文案`
- `真人口播视频生成` 当前支持直接编辑标题和标签
- 真人口播开启 `背景锁定` 时，不再把详细背景计划文案直接提交给 Vidu，避免触发上游审核拒绝
- 视频后处理当前依赖服务端 `ffmpeg + ffprobe`，用于音频合成、时长探测和字幕烧录

## 认证与接口
- 登录页已接真实后端认证，不再使用纯前端假登录
- 当前认证链路为 `/api/auth/login -> /api/auth/me -> 本地持久化 accessToken`
- 前端会生成稳定 `deviceId` 与设备名，用于后端设备会话挤占
- 401 未授权已做统一处理，前端会自动清空登录态并跳转重新登录
- 当前已提供根路径 `/` 与 `/health` 作为最小健康检查接口

## AI 与模型配置
- `社媒图文生成` 已接通后端真实接口，服务端会并行生成文案与图片并写入结果表
- `商品图与详情图生成` 已接通真实文案生成与图片生成接口，但结果当前仍写前端草稿流
- 模型配置页当前主语义是 AI 模型配置，不是关键词规则
- 模型配置已接通后端真实接口，支持查看当前配置、测试连接、保存并激活
- 模型配置接口当前为 `POST /api/ai/model-configs/:type/test-connection` 与 `POST /api/ai/model-configs/:type/activate`
- 当前模型配置存储介质为 Redis，不走业务数据库

## 获客内容池
- `Publishing` 页面当前已实现内容池列表、发布记录与上传超级站入口
- 草稿箱“同步到获客”当前会把素材写入前端本地内容池 store
- 独立后端内容池表、发布任务表与正式接口仍未落地

## 知识库
- 知识库前端仍以 demo 页面与检索测试台为主
- 后端 Prisma 已补齐知识库文档、切片、任务三类表结构与状态枚举
- 已接入 PDF、DOCX、OCR、向量化相关依赖，为后续知识库链路落地做准备
